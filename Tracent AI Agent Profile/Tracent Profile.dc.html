What it does

Atlas takes a natural-language question and returns a sourced, structured brief. It plans a search strategy, queries the open web and a set of licensed databases, reads and cross-checks the results, then writes a summary with inline citations back to primary sources. It is built for analysts, journalists, and operations teams who need defensible answers rather than a single best guess — every claim in its output links to where it came from. Atlas runs as a hosted service and as a self-hostable package, and exposes its capabilities over MCP and A2A so it can be dropped into existing agent workflows.

A community researcher showed that a crafted web page could coax the agent into echoing snippets of prior task context in its summary output. Affected long-form runs that ingested untrusted pages directly. Cartograph Labs shipped input-isolation and output-scrubbing in v2.6 (Feb 25, 2026) and credited the reporter. No confirmed real-world data loss.
Roughly 3% of multi-source summaries returned plausible but non-existent source URLs, traced to an over-eager citation formatter. Fixed in v2.4 with live URL validation against the retrieved source set.
Two partner sites reported elevated 429 (rate-limit) responses traced to the agent's parallel fetch behavior. Default concurrency was lowered and per-domain backoff added the same week.
